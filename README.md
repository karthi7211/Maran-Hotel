# 🍽️ Cashier Billing System

A mobile-optimized cashier billing system designed for restaurant reception staff. This app helps cashiers quickly add customer orders, calculate totals, and generate QR codes for easy payment processing.

## 🎯 Purpose

This system is specifically designed for **cashiers at the restaurant reception** to:
- Quickly add items that customers have ordered
- Calculate total amounts instantly
- Generate QR codes for customer payments
- Print bills for customer records
- Process orders efficiently on mobile devices

## 📱 How to Use (For Cashiers)

### 1. **Taking an Order**
1. Ask customer what they ate/ordered
2. Tap the corresponding items on the menu
3. Adjust quantities using +/- buttons if needed
4. Watch the total update in real-time

### 2. **Processing Payment**
1. Tap "Generate QR & Bill" when order is complete
2. Show the QR code to customer for payment
3. Print bill if customer needs a receipt
4. Tap "New Order" to start the next customer

### 3. **Managing Orders**
- **Clear Cart**: Remove all items and start over
- **Adjust Quantities**: Use +/- buttons to modify item quantities
- **Remove Items**: Tap × to remove specific items
